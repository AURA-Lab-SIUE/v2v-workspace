# 03_Data

Sampled data, coding, and analysis, from Chapters 10 to 12.

Keep the raw sample and your coded output as separate files. Never edit the raw sample
in place; if you do, you cannot show anyone how you got from it to your results.

A workable layout:

```
raw/          the sample exactly as drawn, never modified
coded/        your coding output
analysis/     the .qmd or .R that turns coded data into results
```

**Do not commit data you are not licensed to redistribute.** If a dataset came with
terms, respect them. Course practice data comes from the `v2v` package, so you do not
need to commit that at all; load it with `library(v2v)`.
