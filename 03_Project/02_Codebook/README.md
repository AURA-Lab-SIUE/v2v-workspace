# 02_Codebook

Your coding instrument, from Chapter 8.

Start from `_templates/codebook.md`. It follows the book's five-part structure: unit of
analysis, variables and categories, decision rules, examples, and special cases.

The codebook is the instrument, not paperwork written afterward. Two coders running it
on the same input should produce the same output.

Keep every version. The revision log is what lets you explain in your methods section
why a category changed.
