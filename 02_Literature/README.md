# 02_Literature

Reading notes and Zotero annotations. One file per source.

Name files so you can find them by author and year: `neuendorf-2017-content-analysis.md`.

Useful things to capture per source: the claim, the method, the sample, what it does not
establish, and one line on why it matters to your study. That last line is the one that
saves you when you write the literature review.
