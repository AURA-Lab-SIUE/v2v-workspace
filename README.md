**Your personal research workspace for MC 451 / MC 501, in VS Code.**

> Status: stub. More to come before Fall 2026. The folder skeleton and journal
> template below are in place; lab starter files, codebook templates, and the
> `00_START_HERE.md` walkthrough are being added over the summer.

## How to use this template

1. Click **Use this template** > **Create a new repository** (name it e.g. `mc451-methods-vault`).
2. In VS Code, run **Git: Clone** and open your new repository.
3. Accept the **recommended extensions** prompt (Foam, Quarto, R, Markdown All in One).
4. Copy `_templates/journal-entry.md` into `01_Journal/` each week and write your reflection.

Full setup guide: https://aura-lab-siue.github.io/v2v-hub/resources/methods-vault-setup.html

## Structure

```
00_Inbox/        Quick capture for unprocessed notes
01_Journal/      Weekly reading reflections (committed to GitHub)
02_Literature/   Reading notes and Zotero annotations
03_Project/      Your research project hub (prospectus, codebook, data, drafts)
04_Resources/    PDFs, images, attachments
05_Textbook/     Chapter links for offline reading
_templates/      Reusable templates (journal, codebook)
.vscode/         Recommended extensions and workspace settings
```

Notes are plain Markdown. With Foam you get `[[wiki-links]]`, a backlinks panel,
and a graph view, turning these files into a connected research archive.
