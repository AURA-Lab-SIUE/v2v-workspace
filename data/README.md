# data

Your data files: the sample you drew, your coding sheets, and the files your R code saves.

The course guides and the Twitch worksheets keep every data file here, and their R code names
the folder in each path, such as `read_csv("data/coding-form.csv")`. R reads the path the code
gives it, so a file has to sit in this folder for those lines to find it. The AURA Lab R
Companion saves your reliability codes in `data/derived/`.

Save a coding sheet as a CSV file (in Excel or Google Sheets, a `.csv` download; in Numbers,
**File**, then **Export To**, then **CSV...**), then drag it onto this folder in the VS Code
Explorer.

**Do not commit data you are not licensed to redistribute.** If a dataset came with terms,
respect them. Write where your data came from and how you sampled it in
`03_Project/03_Data/`.
